# Pramana — live assessment service

The hosted T1 engine behind **Assess a model** on https://pramana-f0eb7.web.app.
A FastAPI service that scores an uploaded ResNet-18 state dict against the fitted
64-model null, signs the verdict with Ed25519 and chains it into the ledger.

This repository is **private**: it carries the statistical engines (`pramana/`) that the
public repository leaves out.

```
api/live_app.py       HTTP API: submit, poll, ledger, health
api/live.py           the T1 assessment: FP32 → INT8 / pruned / TorchScript, nulls, verdict
api/live_store.py     jobs + hash-chained ledger in Firestore (in memory when unset)
pramana/              the engines
backend/assets/       fitted baseline, committed images (Battery A, calibration), 2 samples
```

## Deploy on Render

1. Push this folder to a **private** GitHub repository.
2. Render → **New → Blueprint** → pick the repository. `render.yaml` creates the
   `pramana-api` web service (Docker, free plan).
3. In the service's **Environment** tab set:
   - `PRAMANA_ACCESS_CODE`: the code you give judges
   - `FIREBASE_SERVICE_ACCOUNT`: the full service-account JSON (see below)

   `PRAMANA_SIGNING_SEED` is generated by Render. Keep it stable: changing it changes
   the ledger's signing key.
4. Wait for the first build (about 5–8 minutes). Then open
   `https://<service>.onrender.com/api/live/health` and look for `"ready": true`.

## Firestore (ledger and jobs survive restarts)

Firebase console → project `pramana-f0eb7`:

1. **Build → Firestore Database → Create database**, production mode. This is free on
   the Spark plan.
2. **Project settings → Service accounts → Generate new private key**. Paste the whole
   JSON into Render's `FIREBASE_SERVICE_ACCOUNT`. **Never commit this file.**

Without `FIREBASE_SERVICE_ACCOUNT` the service still works, but jobs and the ledger are
lost whenever the free instance sleeps.

## Endpoints

| Method | Path | |
|---|---|---|
| GET | `/api/live/health` | readiness; the website pings it to wake the instance |
| POST | `/api/live/assessments` | form: `access_code`, and `sample` or `file` |
| GET | `/api/live/assessments/{id}` | status, stage, log, result |
| GET | `/api/live/ledger` | every ledger row and the public key |

## Run locally

```bash
pip install torch==2.5.1 --index-url https://download.pytorch.org/whl/cpu
pip install -r requirements.txt
uvicorn api.live_app:app --port 8765
```
